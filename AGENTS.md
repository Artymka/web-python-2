# Agents.md — Правила разработки и описание проекта

## 1. Тема проекта
**Система управления вычислительными задачами (Computational Task Management System)**. 
Проект представляет собой программный комплекс, состоящий из:
1. Утилиты командной строки (CLI) для выполнения вычислительных задач (Этап 1).
2. HTTP API на базе Flask для управления задачами, сессиями и отчетами (Этап 2).
3. Слоя доступа к данным на базе реляционной СУБД SQLite с использованием ORM PonyORM (Этап 3).

## 2. Модель данных (ER-диаграмма)
Модель данных состоит из трех сущностей: `Session`, `Task`, `Completion`.

### Session (Сессия)
*   **key** (int, PK) — первичный ключ.
*   **datetime** (int) — время создания.
*   **ip** (str) — IP-адрес.
*   **locale** (str) — локаль.
*   **user_agent** (str) — User-Agent клиента.
*   *Связь*: Один ко многим с `Task`.

### Task (Задача)
*   **key** (int, PK) — первичный ключ.
*   **datetime** (int) — время создания.
*   **parameter** (str) — параметр задачи.
*   **session** (int, FK) — ссылка на `Session.key`.
*   **description** (str) — описание задачи.
*   **done** (int) — статус выполнения (0/1).
*   *Связь*: Один ко многим с `Completion`.

### Completion (Выполнение)
*   **key** (int, PK) — первичный ключ.
*   **datetime** (int) — время завершения.
*   **response** (str) — результат (ответ).
*   **stage** (str) — этап.
*   **error** (str) — текст ошибки (если есть).
*   **task** (int, FK) — ссылка на `Task.key`.

## 3. Правила оформления репозитория (Git и Код)
При разработке строго соблюдаются следующие ограничения:

### Структура репозитория (C1-C6)
*   В корне обязателен `README.md` (описание, функции, сборка, примеры).
*   Обязателен `.gitignore` (исключить `__pycache__`, `.venv`, бинарники).
*   Исходный код только в папке `src/`.
*   Тесты только в папке `tests/`.
*   Обязателен скрипт запуска `run.sh` (или `Makefile`).
*   Коммиты строго по спецификации **Conventional Commits** (например, `feat: add api endpoint`, `fix: fix header validation`).

### Запрещенные файлы (G1-G5)
*   Никаких архивов, бинарников, служебных файлов Python, артефактов сборки и файлов настроек редакторов (`.idea`, `.vscode`).

### Качество кода (P1-P5, П1-П5)
*   Файлы не более 1000 строк.
*   Строки кода не более 80 символов.
*   Функции не более 40 строк.
*   Аргументов функции не более 7.
*   **Только docstring** (без обычных комментариев `#` внутри кода).
*   Соответствие стандарту **PEP8**.
*   Запрещены "магические числа" (все константы должны быть именованы).
*   Цикломатическая сложность не должна быть превышена (избегать глубокой вложенности).
